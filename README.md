## ✅ ฟีเจอร์ที่มี

- คลังวัสดุกลาง 44 หมวด · ค้นหา · เทียบ · รูป · ลิงก์ผู้ผลิต
- จัดการโครงการ + ผังห้อง + Room Finish Schedule
- ทางเลือกวัสดุ A/B/C · สถานะอนุมัติ · ประวัติราคา
- รหัส MasterFormat Division อัตโนมัติ
- **ลิงก์นำเสนอลูกค้า** — เลือกโชว์/ซ่อนราคาได้ ไม่มีข้อมูลต้นทุนหลุด
- **ตัวเลือกอุปกรณ์เสริม (AC)** — ดึงจากหมวด AC เท่านั้น ออกรหัสให้อัตโนมัติ
- **ก๊อปรายการข้ามหมวด** — ไม่ลบของเดิม กันรหัสซ้ำ
- ลิงก์ "เปิด Sheet" เด้งตรงแท็บ (ฝัง gid ครบ 44 แท็บ)
